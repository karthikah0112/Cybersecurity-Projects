# Cybersecurity-Projects
This repository contains a collection of projects and coursework completed during my MSc in Cybersecurity. The work showcases my skills in various cybersecurity domains, including digital forensics, penetration testing, cryptography, risk assessment, and incident response. Each project reflects my ability to apply theoretical knowledge to real-world cybersecurity challenges, and I’ve employed a range of tools and methodologies throughout.

Projects and Reports:

1. Assessing Cyber-Physical Risks in Metro Stations: A layered approach to enhancing security and resilience.
2. Simulation-Based Optimization and Cybersecurity Analysis of Warehouse Management Systems: A detailed study on optimizing security in warehouse management.
3. Comprehensive Digital Forensic Investigation Report: A thorough analysis of a data breach at Dark Clarke.
4. Exploring the Effectiveness of Steganography Tools: Analysis of data concealment, robustness, and steganalysis.
5. ATP Group Badrory: A critical analysis of techniques, tactics, procedures, and comparative research.
6. Penetration Testing Report for Luke's Wholesaler: Comprehensive vulnerability assessment and security analysis.
7. Information Security Management & Governance Report for Plymouth Food Emporium: Security and governance measures for a food industry client.
8. Cryptographic Strategies for Replay Attack Prevention: An analysis using timestamps and nonces in CrypTool.
9. Security and Privacy Analysis of a Location-Based Tracking System: Evaluating the privacy implications of location tracking technologies.
10. Comprehensive Cybersecurity Analysis and Intrusion Response Framework for Devon Cinema**: Security analysis and response framework for a cinema network.
11. Intrusion Analysis Report for Devon Cinema Network Incident: Detailed report on a network intrusion incident.

These projects are part of my continuous journey to deepen my expertise in cybersecurity and demonstrate my hands-on skills in real-world scenarios. Feel free to explore and connect if you are interested in discussing any of these projects or collaborating on cybersecurity-related topics.
